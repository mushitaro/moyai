# 2026-11-16 作業画面の英語と日本語（作業役。運営者「グローバル対応」）

統括から頼まれた分。作業画面（src/app）を英語と日本語の 2 つにした。日本語はそのまま、英語を足した。AI が読む文（tools・instructions・data-names・skills・packs）と取り込みの見出しの読みは範囲の外（別の作業役）。

## したこと

- 仕組み `src/app/text/i18n.ts`：`defineMessages(en, ja)`。英語の表が元（型はここから）で、日本語の表は同じ形を型で強いる（足りない鍵・余る鍵・引数の違いは `npm run typecheck` で落ちる。`tests/unit/i18n.test.ts` に `@ts-expect-error` の試験）。返すのは今の言語の表を読む生きた表で、`const S = TEXT.shell` のように先に取っておいても、読むときの言語になる。`setLang` で購読（`subscribeLang`・`use-lang.ts` の `useLang`）が呼ばれ、`App` から下が読み込み直しなしで描き直る。`withLang`・`messagesIn` は画面の言語を変えずに別の言語の字を作る（Excel の出力・公開の台帳のページ・AI に返す結果）。React は持たない（橋渡しの出力からも読む）。
- 言語の選び方：設定（`settings.json` の `lang`）→ この PC のブラウザに覚えた写し → `navigator.languages[0]` が ja で始まれば日本語、ほかは英語。橋渡しは握手（`bridge.welcome` の `lang`）で設定の言語を渡す。画面の外（node）は日本語（node 22 にも `navigator` があるので `document` で分ける）。
- 設定：絵（Wire Frame の Settings.dc.html の表示の節）に「言語　English | 日本語」を足してから、`LangChoice` を作った。押すとすぐ描き直して `settings_save`（`lang`、送ったときだけ変える。null は消す）。`settings_read` が返す。
- 字：`src/app/text/` の `index.ts`・`human.ts`・`reasons.ts`・`review.ts`・`site.ts`・`photo.ts` の英語の表（`src/app/text/en/`）。ページと部品に残っていた区切り・括弧・「理由：」などは `src/app/text/inline.ts` に寄せた。`src/plan/due-view.ts`（次回の列。画面と Excel が同じ字）も 2 つにした。英語の画面の版の呼び名は和暦でなく西暦の年度（`FY2026 edition (v1)`）。
- 出力：`EXPORT_TEXT` を 2 つにし、`planWorkbook` は `lang`（確定・戻すのときの設定の言語）で書く。無ければ日本語（今までの出力のまま）。公開の台帳のページは `moyai ledger site … --lang en|ja`（既定 ja）と `<html lang>`。
- 英語にしない字（データ・署名・AI）：施設名の【架空】の印（`MoyaiTop`・`ReadingsSheet`・取り込みの架空の見分けは画面の字でなくデータの字を使うように直した）、紐付けの basis（`crosswalk-basis.ts`）、写真のツールの結果（`photo-tool.ts`）、取り込みの読込の注記（`intake-tool.ts`）。AI に返す `chart_rows`・`check_results`・`chart_propose` の行の字・`share_preview` は、画面の言語によらず日本語で返す（`withLang("ja")`）。
- 用語：`docs/words.md` §4 に英語の列（星取表は初出で「Maintenance schedule (Hoshitori)」、号炉 → Unit、年度 → FY など）。`docs/screens.md` §1 に言語の行。
- 試験：`tests/unit/i18n.test.ts`（登録したどの表も英語と日本語の形がそろう・型の検査・切り替え・購読・PC の言語）、`tests/unit/lang-settings.test.ts`（settings の lang・settings_save と read・握手の lang・Excel の言語）、`tests/unit/share/site.test.ts` に英語のページ、`tests/unit/sign-words.test.ts` に英語の版の呼び名。e2e は `tests/e2e/lang.spec.ts`（押すと読み込み直しなしで英語・設定に残る・設定が日本語なら英語の PC でも日本語）と `tests/demo/walkthrough-en.spec.ts`（英語のブラウザで walkthrough を端から端まで。台本は `walkthrough-flow.ts` に移し、日本語の `walkthrough.spec.ts` と同じものを言語を渡して呼ぶ。期待する字は画面と同じ表から、その言語で読む。日本語の期待する字は前と同じになることを確かめた）。`scripts/scenario/run.mjs` の walkthrough に英語の台本を足した。
