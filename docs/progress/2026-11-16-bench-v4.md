# 2026-11-16 日誌：物差しの新しいサンプル v4 を別のリポジトリから測る用意（#111）（作業役）

統括から頼まれた分。運営者の判断（11-14）で、v4 のサンプル（11 施設・2,565 ファイル・約 440 MB）は MOYAI 本体に入れず、別の公開リポジトリ `mushitaro/moyai-samples` に置く。そのリポジトリはまだ無い。サンプルの中身は見ていない。枝は `claude/bench-v4-external`。

## したこと

1. `scripts/bench/freeze.mjs`：サンプルがリポジトリの外（別のリポジトリの clone の中のフォルダ）でも check・measure できる。
   - 外のときは「タグの木にサンプルが無い」の代わりに、サンプルのリポジトリの commit（40 字）・中の道・出どころの URL（鍵は除く）を `freeze.json` の `source` に記録する。
   - サンプルの側に commit していない変更があれば測らない。測っているあいだに commit か中身が替われば止まる。
   - 凍結の測りは 1 回だけ。読み手は `reader-freeze-7`（c73c815）のまま。タグの worktree の pack-bench で測る形も変えていない。
2. 記録の置き場所：`eval/bench/waste-incineration-v4/`（`frozen/` と今の記録）。
   - `scripts/bench/v4.mjs`：名前・サンプルのリポジトリ・凍結の記録の読み・資料の少ない施設の選び。
   - `scripts/scenario`：v3 を v4 に替えた。判定の字は「v4、mushitaro/moyai-samples の凍結の測りがまだ」。
   - `docs/scenarios.md` の S-A の注と `eval/bench/FREEZE.md` を書き直した。v3 は運営者が不合格にしたこと、v4 は別のリポジトリにあること、測る場所。
3. CI（`pack-bench` の仕事）：`frozen/freeze.json` があるときだけ、`mushitaro/moyai-samples` を記録した commit で取る。
   - (a) 凍結の記録の照らし：`tests/heldout/bench-freeze.test.ts` に、外のサンプルの確かめを足した（`MOYAI_SAMPLES_ROOT`。`MOYAI_SAMPLES_REQUIRED=1` なら clone が無いと落ちる）。
   - (b) 資料の少ない 3 施設を測り、今の記録の同じ施設の行と `--strict` で比べる（`scripts/bench/v4-ci.mjs`）。
   - 結果は仕事の出力 `v4` で `scenario` に渡す。履歴とタグを全部取る（`fetch-depth: 0`）。
   - 凍結の記録が無いあいだは「待ち（#111）」。
4. 通しの試験 `tests/scripts/bench-freeze-external.test.mjs`：偽の小さなサンプルのリポジトリ（一時の git。旧サンプルの 2 施設を写す）と、このリポジトリの一時の clone で走らせる。本当の記録は書き換えない。
   - いつも：check が通る。commit していない変更・git の外・凍結の記録がもうある、を断る。出どころに鍵を出さない。
   - `MOYAI_FREEZE_FULL=1`（CI の pack-bench の仕事）：measure → `freeze.json` → 2 回目は断る → 照らし → 比べ。サンプルの commit が替われば、照らしも比べも落ちる。
