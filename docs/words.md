# MOYAI の画面の言葉

画面に出す言葉の決まり。Wire が持つ。運営者が画面の写しに書いた直し（2026-11-05）と、そこから読んだ好みで決めた。絵は canvas（V57）。

## 1. 好み（運営者の直しから）

- **業務の熟語で短く。** 読取・照査・詳細・差異・反映・非該当・新規・未承認・確定者・基準外・基準内。動詞の言い回し（「決まっていない」「受けていない」「確かめました」）にしない。
- **状態は名詞と数。** 「未確定 1」「承認不可」「未照合」。
- **説明の文を置かない。** 「あなたの承認を待っています」「承認すると、この版は確定のまま…」「版の中身は変わりません」は消す。外へ出す前の結果の文だけを、短く残す（「GitHub に PR を送信。掲載後は取り下げても複製は残ります。」）。
- **比喩・造語を使わない。** 指紋・合言葉・写し方・列の役目・落とす・束・輪・もやいは使わない。
- **パスワードは無い。** 合言葉の欄はどこにも置かない。

## 2. 置き換え

左を右へ。言葉が文の中にあるときも同じに直す（運営者＝写しへのコメント、Wire＝好みから当てたもの）。
