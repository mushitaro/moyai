# S-0 初めての人の通し：運営者の手順（M-PC3）

`docs/scenarios.md` の S-0・A4・D4・E3 を、運営者が M-PC3 の Claude Desktop で 1 回通すための手順です。所要はおよそ 30 分。押すのは画面の主ボタンだけで、ほかは Chat に言うだけです。結果は統括が `eval/scenario/result.md` の実機の列に書きます。

## 始める前に

- Claude Desktop を 1 回閉じて開き直す（自動の更新が新しい版にしている。E3）。
- 作業画面の右下のビルドの字が、統括が知らせた版になっているかを見る。→ **E3 の確かめ**

## 手順

| 順 | あなたがすること | 見るところ（合格の条件） | 印 |
|---|---|---|---|
| 1 | （済み）MOYAI は版ごとのフォルダに入っている | Desktop に MOYAI のツールが出る | S-0 の 1 |
| 2 | Chat に「デモして」 | デモの施設の星取表が出る | S-0 の 2 |
| 3 | Chat に「このフォルダの資料で星取表を作って」と、業種のパックが無い施設のフォルダ（統括が用意して知らせる）を渡す | Claude が 1 年分から読み、問いに答えると、残りの年度も入って計画ができる。迷った所・分からなかった問いをメモ | A4 |
| 4 | HOSHITORI の確定のシートを開き、主ボタンで受け、署名して確定する | 選ぶ・入れる欄が出ない。押すのは主ボタンだけ | D4 |
| 5 | HOSHITORI の出力のシートで、主ボタンで Excel を落とす。Excel で開く | Excel で開いて読める・見やすい | D4 |
| 6 | HOSHITORI の共有のシートで、主ボタンで共有フォルダに出す | 送信のあとの 1 行が出る | D4 |
| 7 | 統括が main を進めたと知らせたら、Desktop を開き直す | 新しい版になっている（右下のビルドの字） | E3 |

## 終わったら

Chat か統括に、次の 3 つを 1 行ずつ返してください。

- 迷った所があったか（どの順の、どの画面か）
- Excel は見やすかったか
- 3 の問いで、分からなかった問いがあったか
