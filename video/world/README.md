# 動画の撮り直し用の世界（ほたる川クリーンセンター）

動画の撮り直し用に、デモの世界を 1 つにそろえる。すべて架空（中に【架空】と書いてある）。今の fictional-1 と `packs/` のデモの資料は変えていない。

| 人・施設 | 役 |
|---|---|
| 【架空】ほたる川クリーンセンター | 主役の施設。ストーカ炉 2 炉。令和 6〜8 年度 |
| 【架空】佐藤 | 整備の担当。Claude のチャットで答える人。版を作って承認を頼む |
| 【架空】山田 | 市の環境課。承認する人。宛先は yamada@example.jp |
| 【架空】しらかば野クリーンセンター | 客先。ほたる川の第 2 版から派生した枝と、3 段目の Skill を受ける |
| さくら坂 | 客先。この仕事では履歴を作らない（下の「しないこと」） |

## 置いてあるもの

- `hotarugawa/` 資料。施設台帳・星取表・作業日報（今のデモと同じ種類と形）と、正解の世界 `world.truth.json`。作り手（`samples/factory/`）が決まり `world/rules-hotarugawa.json` から作る。作り直しは `python -I -X utf8 samples/factory/video_world.py`、置いたものが作り直しと同じかは `--check`。
- `make-history.mjs`・`history-core.ts`・`guard.mjs` 版の履歴の台本（撮る前に使う）。
- `walkthrough.spec.ts`・`playwright.config.ts`・`rules.ts` デモの通し（caps）。`tests/demo/walkthrough.spec.ts` と同じ道を、この世界で通す。

## 撮る前の手順

1. `npm ci --ignore-scripts` のあと `npm run build`。
2. 空の保管先（フォルダ）を作る。運営者の本物の保管先は使わない。道に `MOYAI` の名前のフォルダを含めない。
3. 履歴を作る：
   ```
   node video/world/make-history.mjs --store <空のフォルダの絶対の道> --mail-out <メールの文を書くファイル（まだ無いもの）>
   ```
   `--now <ISO の日時>` で、版の日時の数え始め（撮る日）を変えられる。既定は今。版の日時は撮る日から数える（トップは直近 20 か月の列だけを描くため）。
4. MOYAI（`moyai start`）の設定で、保管先をそのフォルダにする。呼び名は 佐藤（整備の担当）の画面は「【架空】佐藤」、山田の画面は「【架空】山田」。山田の画面は別の状態フォルダの MOYAI（`MOYAI_STATE_DIR` を別に）にする。
5. 山田の MOYAI で、メールの文の中のリンク（承認待ちの令和 8 年度版）を開くと、承認の頼みを受けて承認できる。

作るもの：

- ほたる川：第 1 版（令和 6 年度版）・第 2 版（令和 7 年度版）は、佐藤が作って渡し、山田が承認して署名した。第 3 版（令和 8 年度版）は佐藤が渡して、山田の承認待ち。
- しらかば野：第 1 版。ほたる川の第 2 版から派生した（トップで線がつながる）。3 段目の Skill「【架空】ほたる保全の読み方」（会社の読み方。誘引の呼び名の替えと、★ の意味）を、ほたる川の第 2 版としらかば野の第 1 版が使う。
- 署名の鍵は、台本が走るたびに作る架空の鍵。秘密鍵は書かない。台本が終われば、その鍵で署名することはできない。山田の画面の鍵は山田の MOYAI が作った別の鍵になる（未確認：画面でどう見えるか）。

断る場合（上書きの旗は無い）：保管先が絶対の道でない・道に `MOYAI` のフォルダがある・状態フォルダの設定の保管先と重なる・状態フォルダと重なる・空でない。終了コード 3。

## デモの通し

空の保管先から始める流れ（履歴を作らない）。`npm run build` のあと：

```
MOYAI_SHOTS_DIR=<出す先> npx playwright test -c video/world/playwright.config.ts
```

画面の Chrome が要る。この台本は、この仕事の中では画面で通していない（未確認）。通し以外の部分（取り込み・当てはめの規則）は `tests/unit/video-world-intake.test.ts` で、ブラウザなしに通している。

## しないこと

- さくら坂の履歴は作らない。
- 公開の台帳のデモ（`scripts/ledger/`）の 10 施設は変えていない。通しの公開の台帳の場面は、その施設を使う（名前は変わっていない）。
