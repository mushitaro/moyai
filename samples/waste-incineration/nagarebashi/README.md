# 【架空】ながれ橋清掃工場（架空東郷広域環境組合）— サンプルの世界

すべて架空の施設です。実在の自治体・施設・会社・人とは関係ありません。施設の性質の分布だけを、公開の統計から加工して使いました（下の「出典と加工」）。

この README は作る側と測る人のためのものです。読み手（AI）には渡しません。読み手の質問に答える役が見るのは `user.md` と `answer/world.json` だけです。

## わざと入れた揺れと食い違い

### 1. 資料の汚さ（取り込みが読み切るもの）

- `【架空】ながれ橋_整備計画_H29-R11.xlsx`：名前は 1 列。段は全角の空白で字下げし、深い段は「・」を付けた。年度の見出しは「R2年度」を 2 列に結合し、その下に予定・実績。凡例：年度ごとに「予定」と「実績」の 2 列。予定の欄の ○ は当初の計画、実績の欄の ● はやった年、△ は一部だけ。古い年度の列を 1 列隠した（H29〜）。周期を「2年」と文字で書いた行が混ざる（数の行と文字の行）。号炉の書き方が機器ごとに揺れる（1号炉・１号炉）。1 台ずつの行と、2 炉で 1 行・台数をまとめて 1 行の機器が混ざる。Excel のメモ：延期の理由（「R2予定 → R3に延期」）、計画外の臨時の実施、完成図書との名前の違い。備考に取替・新設・更新（「R3 更新」）と、文の中の年度（「R18に更新の予定」）、事後の補修（「R5.3.8 …（臨時）」）。自分の作業を持つ親の行（整備計画 の 22 行「受入供給設備 › ゴミクレーン › 1号機」に「年次自主検査」、その下に子の行。ほかに 16 行）。設備ごとの小計と年度ごとの合計（数の値）。合計の行が表の上。費用は円（ほかの施設は千円）。未来の年度の列を網掛けで分けた。
- 発注台帳（H29〜R7）：年度ごとのシート。H30 年度までは和暦の文字の日付（「H27.5.12」と「平成27年5月12日」が混ざる）、あとは日付のセル。単価契約（予定総額と支払額が違う）、変更契約の行（「　〃　（第1回変更）」）、緊急の随意契約、定期補修工事の一式。件名に施設の正式名と略称が混ざる。区分ごとの小計と合計（数の値）。履行期間を 1 つのセルに「R8.4～R9.3」と書いた

### 2. 資料どうしの書き方の違い（同じ機器・同じ作業を、資料ごとに違う形で書いた）

- 粒度：完成図書・機器台帳は台数でまとめ、星取表は 1 台ずつの行・2 炉で 1 行・まとめて 1 行が混ざる。台帳の 1 行が、星取表では部位（クレーン → 巻上装置・走行装置・横行装置・バケット など）に分かれる
- 日付：星取表は年度の印だけ。日報・工程表・発注台帳は日付（工程表の着手・完了と、日報の作業した日は同じ作業。発注台帳の工期は契約の期間で、作業の日より広い）
- 工数：日報は 1 日の人数（と延べ時間）、工程表は延べ人工（数か文字）か日数だけ、CSV は人数と時間。同じ作業の日報の人数の和が、工程表の延べ人工になる
- どの資料のどの行がどの作業かは `answer/world.json` の `links`（`how` が bundle・annual・rollup・upgrade の結びは、契約やまとめた工事の行で、作業そのものの行ではない）
- 事後の補修は、星取表にはほとんど書かない（一部だけ備考か「補修（事後）」の行）。日報と発注台帳の修繕工事にはある

## 正解の形

- `answer/files/<stem>.json`：ファイルごとの正解（作り手への指示書 §5.1）。Excel は `sheet` と `r`、CSV は `r`（1 行目が 1）、PDF は `seq`、写真は `seq` と `image`。
- 星取表の `path` は名前の頭の番号（「1.」「(1)」「■」）と字下げの空白・「・」を外した名前の並び。「〃」の行は意味の名前で書いた。`code` は機器番号の列があるときだけ。
- 予定と実績を 2 列に分けた星取表は、実績の列を `marks`、予定の列を `plans` に入れた。3 年度にまたがる結合のセル（基幹改良）は、結合が掛かる年度すべてに同じ文字を入れた。
- 写真の正解で、影やぼけで読めなくしたセルは「読めない」。
- `answer/world.json`：機器（1 台ずつ）・作業（属性・日付・工数・業者・契約）・契約・結び（`links`：どの資料のどの行がどの作業か）・書いていない作業と理由・計画の欠け・書き漏れ・施設の性質。
- `gen/evidence/<stem>.json`：正解の値が書いてあるセルの番地と値（`check.py` が照らす）。

## 出典と加工

- 施設の性質（炉型・処理能力の帯・蒸気タービン・灰処理・運営の形）は、環境省「一般廃棄物処理実態調査結果（令和 6 年度）施設の表（焼却施設）」から数だけを取り出した `packs/waste-incineration/national/table.json` の分布に寄せて選んだ（加工した）。表の行や施設名は写していない。
- 機器の項目は、環境省の長寿命化総合計画作成の手引きの表Ⅱ-4（パックの `common.json`）。法令の点検の周期は、照らしたもの（精密機能検査の 3 年＝課長通知）だけを `recommendation` にし、ほかは `app`（`world.json` の legal）。
- 金額・工数・業者・型式・製造番号・人名はすべて架空。
