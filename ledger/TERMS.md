# 利用条件

この台帳は、MOYAI の束（施設ごとの、共通の設備項目 × 作業の属性の、周期・工数・日数の帯）を集めます。

- 共有する値は、塊の周期・工数・日数・最初の作業のときの経過年の**帯**と、作業をした年度の一覧だけです。**費用は共有しません**（束に費用の欄はありません。どの決まりでも足せません）。
- 生の工数・日数・日付・人・業者・備考・施設名は、束に入りません。束は、送る側の PC の検問所で人が確かめ、合言葉で署名したものです。
- 束のファイルは誰でも開けます。PR を出した GitHub アカウントは誰にでも見えます。台帳専用のアカウントを勧めます。
- 検証（形・署名・鎖・粒度・禁止語・数え直し・紛れる数 k ≥ 5）は、MOYAI と同じ関数を GitHub Actions で走らせて行います。マージは管理者（人）がします。
- 会期中（Built with Claude: Japan 2026）は、架空の施設だけを載せます。

保証できないこと（MOYAI の docs/plan.md §2.8 と README にも同じものがあります）：
① 中身が本当かは示せない ② 受け取った人は写せる ③ 全国の表に無い知識との突き合わせは防げない ④ 対応表の誤りは見つけられない ⑤ 束の年度は誰にでも見える ⑥ PR を出したアカウントが残る ⑦ 差分プライバシーは使っていない ⑧ 共有してよいか（契約・独禁法・営業秘密）は、この台帳が決められない。
