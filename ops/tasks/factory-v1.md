# サンプルの工場 v1：資料を 5 種に、深さの違う 2 つ目の施設

`samples/factory/README.md`、今の生成器（`samples/factory/`）、`docs/plan.md` §2.5（資料の組の表・汚さの部品・置き場所）を読んでから作る。v0 の作り（正解の世界 → 書き手、乱数の種と物語の「今日」の固定、【架空】の 2 か所、小計は数の値）を崩さない。今の試験を壊さない。

## 1. 作り込む施設（fictional-1）の資料を 5 種にする

§2.5 の表の 1・3・5 を足す（2 の星取表と 4 の作業日報は v0 にある）。

- **1 機器台帳**（Excel）：設備・機器・仕様・設置年。字下げだけの 1 列で段を表す、番号 1 / 1-1 / 1-1-1、名前の中の機器番号（例「誘引通風機（IDF-1）」）、セルの中の改行、取替・撤去を備考に書く。v0 の世界の資産と同じ同一性の鍵を持つ。
- **3 定期整備の工事報告書**（文字のある PDF。号炉ごと・年度ごと）：帳票の形（表題・件名・工期・明細の表・合計）、頁ごとにくり返す見出し、続紙（「（続き）」）。工数（人・日）と工期を書く。まず帳票を Excel（xlsx）で書き、LibreOffice の headless で PDF にする関数を作る（呼ぶたびに `-env:UserInstallation` で別の設定を使う）。**LibreOffice が無い環境では PDF を作らず、作れなかったことを数えて知らせる**（このサンドボックスでは xlsx まで作り、PDF の変換の関数の試験は soffice が無ければ飛ばしてよい。実際の PDF はメインのセッションが LibreOffice のある PC で作る）。
- **5 日常点検表の写真**（JPEG）：3 の PDF の 1 頁（または点検表の帳票）を pypdfium2 で画像にし、傾き・影・ぼけ・手書きの丸とチェックを Pillow で足す。長辺 1,800px 前後・100KB 前後。PDF が無いときは作らず、そのことを数える。
- 精密機能検査の記録を 2 と 3 に書き分ける（間隔の検査の材料）。
- 正解（`samples/truth/...`）に、どの資料のどの行が同じ作業か（資料をまたぐ同一の作業の対応）を書く。

## 2. 深さと呼び名の違う 2 つ目の施設（fictional-2）

- 同じ工場の世界の決まりから、別の種と別の構成（たとえば流動床式 1 炉）で作る。
- 機器台帳と星取表を、段の数（fictional-1 と違う深さ。片方が 2 段ならもう片方は 4 段）と呼び名（同じ機器を別の名前で書く。例「IDF」「誘引送風機」）を変えて書き分ける。
- 名前は「【架空】」で始め、実在の施設と重ならないように、地名に見えない造語を使う。

## 3. 試験（unittest）

- どのファイルにも【架空】が表題のセルと作成者の欄にある。同じ種で作り直すとバイト列が同じ（zip と PDF の時刻を固定）。
- 正解の資料をまたぐ対応が、書いた資料の行と矛盾しない。
- fictional-1 と fictional-2 で、段の数と呼び名が違う。

## 済んだと言える条件

- verify の 3 つが通る。report.md に、作った資料の一覧（施設・形式・行数）、作れなかったもの（PDF・写真）とその理由、メインのセッションが LibreOffice のある PC で走らせるコマンド、未確認のことを書く。
