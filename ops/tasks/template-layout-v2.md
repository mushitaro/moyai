# 様式の写し方（TemplateLayout）を、運営者の実物の様式で通す：IF で包んだ年度の式と、前のシートを写す階層の欄

template-layout-v1 の続き。運営者の実物の様式（前の仕事の仕様の形のとおり：基本情報・履歴・前期計画・後期計画の 3 枚）で、次の案を置くと止まった。案は Claude が置く形のもの：前期のシートは見出し 7・8 行目、年度 8 行目の G〜O、開始年度のセル D6、階層は入れ子の縦で A・B・C・D、組の行は F 列の「予定内容・予定金額・実績内容・実績金額」、合計の前 31 行目。後期のシートは年度 8 行目の G〜P、続きのシート（前期のあと）。

止まった所（実物で測ったもの）：
1. `layoutYears` が全部の列で null。年度の見出しの式の実物の形：前期 `IF(ISNUMBER(履歴・前期計画!$D$6),履歴・前期計画!$D$6+0,"")`（G8）〜 `…+8`（O8）、後期 `IF(ISNUMBER(履歴・前期計画!$D$6),履歴・前期計画!$D$6+9,"")`（G8）〜 `…+18`（P8）。後期の D6 は `IF(ISNUMBER(履歴・前期計画!D6),履歴・前期計画!D6,"")`。`yearRefOf` は裸の参照と参照＋数の形しかたどれない。
2. `checkLayout` が「「後期計画」の明細の欄 A9 に式がある」で断る。後期のシートの階層の欄は、前期の同じ行を写す式：A9 `IF(履歴・前期計画!A9="","",履歴・前期計画!A9)`、B10・C11・D12 も同じ形。後期の合計 G31 は `SUMIF(後期計画!$F$9:$F$30,"予定金額",後期計画!G$9:G$30)` の形（前期の G31 も同じ形で前期のシートを指す）。

直すこと：
1. `yearRefOf` を、IF・ISNUMBER などで包んだ式の中から「（シート!）セル＋数」を 1 つだけ見つけてたどる形に広げる（同じセルを指す参照が 2 つ以上でも、足す数が 1 つに決まればよい。決まらなければ今どおり null）。
2. 続きのシートで、階層の欄が前のシートの同じ行を写す式なら、名前は書かず（前のシートに書いた名前が式で出る）、行を足すときは式を写して行の番号をずらす。`checkLayout` は、この形の式を「明細の欄の式」として断らない。組のラベルの列（F）は今どおり書く。
3. 前期と後期で、足す行の数と位置をそろえる（同じ行に同じ機器が来る。後期の式が前期の同じ行を指すため）。
4. 試験：上の実物の形（式の字のまま）の架空の様式を試験の中で組み、年度が 2016〜2034 と決まる・後期の階層の欄が式のまま前期と同じ行に名前が出る・行を足したあとの式の範囲・合計の式の範囲。今の v1 の試験はそのまま通す。

触らないもの：`src/import/`、署名される字、`packs/`。
